# Locale catalogs (web/src/i18n)

- Every key exists in `en`, `zh`, `zh-Hant` and `ms`, with the same placeholders exactly once each; the compiler proves key sets, `pnpm check-i18n` proves placeholders, plurals, duplicates and unused keys.
- Voice and punctuation per language are in `web/src/i18n/STYLE.md`; `zh-Hant` terms are in `GLOSSARY.md`.
- Subtitles and hints state the capability in one calm sentence: no defensive disclaimers, no empty-state condition lists, no "restart after changing" instructions (AGENTS.md, code style).
