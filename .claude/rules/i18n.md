# Locale catalogs (web/src/i18n)

- This fork reads English only: `en` is the one catalog and the typed source of every message id. `pnpm check-i18n` proves placeholders, plurals, duplicates and unused keys.
- Never add a `zh`, `zh-Hant` or `ms` catalog, and never restore `satisfies Translation<typeof source>` in an `en` file. After an upstream merge, `.claude/skills/upstream-review/scripts/english-only.sh` removes and rewrites both.
- Voice and punctuation are in `web/src/i18n/STYLE.md`; settled spellings are in `GLOSSARY.md`.
- Subtitles and hints state the capability in one calm sentence: no defensive disclaimers, no empty-state condition lists, no "restart after changing" instructions (AGENTS.md, code style).
