# Oh My CPA v1.0.0

Oh My CPA v1.0.0 is the first release of this fork of
[WizisCool/oh-my-cpa](https://github.com/WizisCool/oh-my-cpa). It carries everything in
upstream [v0.4.6](v0.4.6.md), reads English only, and is published, signed and updated
from this repository alone. The fork's releases run on their own `v1.x` line, so a
version here never shares a number with an upstream release.

## Published by this fork

- **Container image on GitHub Container Registry.** The image is
  `ghcr.io/jrmatherly/oh-my-cpa`, for `linux/amd64` and `linux/arm64`. The Compose files
  default to it, and `OMCPA_IMAGE` still overrides it.
- **The fork's own signing key.** Each release carries a manifest signed with this fork's
  Ed25519 key. The console's updater applies a release only when that signature verifies,
  the manifest names the image repository the console already runs and the version is not
  older, then pulls the image by digest.
- **Releases and update checks from this repository.** The console reads its release feed
  from `jrmatherly/oh-my-cpa`. `OMCPA_OMC_REPO` on the console and
  `OMCPA_UPDATER_PUBLIC_KEY` on the updater container still point a deployment at another
  repository and key.
- **Native packages.** Darwin, Windows, Linux and FreeBSD archives for amd64 and arm64 are
  attached to the GitHub release, with `checksums.txt`.

## English only

- **One reading language.** The console, its messages from the backend, the documentation
  and the README are English. The Chinese, Traditional Chinese and Malay catalogs and the
  language switchers are removed.
- **Older settings keep working.** A deployment that pinned `OMCPA_DEFAULT_LANGUAGE` to
  `zh`, `zh-Hant` or `ms` still starts: the console logs a warning at start-up and reads
  English. A browser that saved Chinese, Traditional Chinese or Malay as its console
  language reads English, and a console whose saved number style was the Chinese one shows
  the compact English style.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to
  `docs/ops/sqlite-operations.md`.
- A deployment that runs upstream's `wiziscool/oh-my-cpa` image is not moved to this fork
  from the console. Change the image once by hand, as described under "Moving from the
  upstream image" in `docs/install/upgrade.md`. Data, ports and settings are kept. A
  deployment whose updater was added with `updater install` runs that command once more
  afterwards.
- This release adds no database migration, environment variable or Compose service of its
  own. The default of `OMCPA_IMAGE` and of `OMCPA_OMC_REPO` changed to this fork's image
  and repository.
- Container images are available on GitHub Container Registry as
  `ghcr.io/jrmatherly/oh-my-cpa:v1.0.0` and `ghcr.io/jrmatherly/oh-my-cpa:1.0.0`.
