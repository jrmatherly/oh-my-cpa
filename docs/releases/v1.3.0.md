# Oh My CPA v1.3.0

Oh My CPA v1.3.0 is a feature release of this fork. It builds on [v1.2.0](v1.2.0.md)
and carries upstream's releases [v0.4.7](v0.4.7.md) through [v0.4.14](v0.4.14.md),
plus the Codex billing-cycle fix that followed them. The console stays English only
and keeps the fork's own image, release feed and signing key.

## Trends

- **A Trends page.** `/trends` joins the navigation. It charts subscription quota
  burn and quota cycles per credential, performance over time (time to first token,
  latency, streaming tokens per second), the models and clients that moved most, and
  a stability panel that groups delivery failures for triage. A refresh action on the
  quota panel re-reads an eligible credential on demand.
- **Recovery actions.** When CPA is unreachable, or a credential's quota reading is
  stale or expired, the quota panel says which and offers the fix in place. A quota
  refresh in one tab is reflected in the others.

## Credentials and OAuth

- **GitHub Copilot.** Copilot is a credential family with its own device sign-in
  flow on `/oauth`, its own filters and dashboard channel, and `copilot/` model
  prefixes in the model square.
- **Global OAuth error rules.** OAuth management gains a panel for CPA's
  request-scoped error rules, saved with a pre-write backup and read back after the
  write.
- **Subscription billing cycle.** A credential's quota details carry a Subscription
  cycle tab with the current and previous billing periods, their usage and a
  projection to the end of the cycle. A renewed monthly Codex plan shows its current
  month, not the whole span since sign-up, and the totals refresh when the cycle
  rolls over.
- **Claude plan detection** reads the organization and seat tier, so Team and
  Enterprise accounts are named as such.
- **Case-only model alias pairs** such as `glm-5` to `GLM-5` are accepted.

## Requests and usage

- **Choose your columns.** The request table's Columns menu shows, hides and reorders
  columns, and the choice is kept with your width preferences.
- **Per-request record log.** A request's drawer can download the record log and
  show the raw log inline.
- **Client attribution** names the Antigravity CLI and the google-genai SDK.
- **Request-body limits** are raised to match what each endpoint stores, and a body
  over the limit is refused with HTTP 413 instead of a generic error.

## Configuration and settings

- **One refresh schedule.** Release checks, plugin store checks, scheduled quota
  refresh, OpenRouter pricing sync and exchange-rate refresh share one scheduler and
  sit together under Automatic Refresh in OMC Settings. Release and plugin checks have
  separate intervals.
- **GitHub token in OMC Settings.** CPA's GitHub token has its own card with a live
  rate-limit probe.
- **CPA server identity.** The System page and diagnostics show the gateway's
  `server-id` when the gateway reports one.
- **Payload replacement rules** accept regular expressions, target roles and JSON
  paths, following CLIProxyAPI v8.0.77.
- **Claude `org:create_api_key` scope** and **custom model catalog sources** are
  exposed under Providers.

## Console

- **Status chips are for events.** Request outcomes, audit events, backup jobs and
  warmup runs keep the tinted chip; a state elsewhere is a quiet pip and a word.
- **Mobile resume.** A console left in the background on a phone keeps its place
  when it returns, and a stale page chunk after an upgrade reloads once from the route
  boundary instead of dropping an open surface.
- **Sign-in showcase** draws the live routing map. Selection bars, small chips, toast
  lists and running buttons share one geometry.
- **Startup banner.** The server prints its version, commit and build time to stderr
  at startup.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to
  `docs/ops/sqlite-operations.md`.
- Migration `071_usage_events_completed_index.sql` runs at startup after an encrypted
  pre-migration backup. It adds one index on `usage_events`; on a large table the
  first start takes a few seconds longer.
- The Claude `org:create_api_key` switch needs CLIProxyAPI v8.0.78 or later. The other
  new settings stay out of the configuration until set.
- A Codex quota snapshot saved before this release carries no billing period, so its
  subscription cycle reads as before until the next quota refresh.
- This release adds no environment variable or Compose change.
- Container images are available on GitHub Container Registry as
  `ghcr.io/jrmatherly/oh-my-cpa:v1.3.0` and `ghcr.io/jrmatherly/oh-my-cpa:1.3.0`.
