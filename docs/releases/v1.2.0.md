# Oh My CPA v1.2.0

Oh My CPA v1.2.0 is a feature release of this fork. It builds on [v1.1.0](v1.1.0.md)
and brings upstream's client lens to the dashboard, so the two model cards can rank
the client programs behind the requests as well as the models.

## Dashboard

- **Models and Clients.** The model usage card's title is a pair of tabs. Clients
  ranks the coding agents, tools and SDKs that sent the requests, with each client's
  mark, tokens, share and cost. The token trend card follows the same choice, and
  carries the tabs itself when the usage card is hidden. The dashboard opens on
  Models.
- **Where client figures start.** Client figures reach back as far as the retained
  request records. A window that reaches past them shows the time the figures start
  from, on whichever card carries the tabs.
- **Steadier switching.** While the next figures load the previous ones stay on the
  card, dimmed, and legends and lists keep their places. The trend's bars move to
  the next drawing when its time grid is unchanged.
- **Naming toggle.** The call model and requested model toggle refines Models only.
  It sits on the trend card, and moves to the usage card when the trend card is
  hidden.

## API

- **Client grouping.** `GET /management/dashboard/models` accepts `group_by=client`.
  Each named group carries the client's `category`, and the reply carries
  `covered_from` when the window reaches past the retained request records.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to
  `docs/ops/sqlite-operations.md`.
- This release adds no database migration, environment variable or Compose service.
- The card's total under Clients counts generation requests only and sums each
  request's normalised token total, the total Insights uses. Under Models it sums
  the total each provider reported. Over a window inside the retained request
  records the two agree where a provider's total already includes cache and
  reasoning tokens, and the Clients total is the larger where it does not.
- Container images are available on GitHub Container Registry as
  `ghcr.io/jrmatherly/oh-my-cpa:v1.2.0` and `ghcr.io/jrmatherly/oh-my-cpa:1.2.0`.
