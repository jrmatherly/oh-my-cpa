# Oh My CPA v1.0.1

Oh My CPA v1.0.1 is a maintenance release of this fork. It builds on
[v1.0.0](v1.0.0.md) and changes nothing in how an installed console behaves. It is
the first release an installed v1.0.0 console can move to through its own updater.

## Links and documentation

- **The fork's own links.** The README, the documentation index and the bug report
  form no longer send a reader to upstream's website or demonstration. The API
  Reference links open the OpenAPI specification in this repository.
- **The demonstration's API link.** A demonstration build served outside the staged
  site opens this repository's specification from its header.
- **Release guide.** The maintainer guide no longer asks for the container package to
  be made public by hand.

## Upgrade notes

- Back up `.env` and your SQLite database or volume before upgrading; refer to
  `docs/ops/sqlite-operations.md`.
- This release adds no database migration, environment variable or Compose service.
- Container images are available on GitHub Container Registry as
  `ghcr.io/jrmatherly/oh-my-cpa:v1.0.1` and `ghcr.io/jrmatherly/oh-my-cpa:1.0.1`.
